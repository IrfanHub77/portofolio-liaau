# Portofolio Tria Aulia Agustin

Portofolio interaktif berbasis pengalaman Three.js Kage dari ThreeUI.

**Profil:** Mahasiswa D4 Perancangan Manufaktur — Politeknik Negeri Indramayu (Polindra)  
**Lokasi:** Widasari, Indramayu, Jawa Barat

## Cara Menjalankan

1. Jalankan server lokal pada folder proyek, misalnya:
   ```bash
   npx serve .
   ```
2. Buka URL lokal yang ditampilkan oleh server.

Atau buka `index.html` langsung menggunakan browser, meskipun server lokal direkomendasikan untuk aset WebGL dan iframe.
